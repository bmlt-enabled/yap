# Bilingual Helpline Setup — Step-by-Step Guide

This guide was created by a Narcotics Anonymous trusted servant who spent considerable time learning how to configure a bilingual YAP helpline.

It provides step-by-step instructions for setting up English and Spanish phone services, from start to finish. 
It is written in plain English and walks you through each necessary step. It is intended for novices to this system to read and be able to actually use.

The instructions include:

- Connect Twilio to Yap (configuration)
- Base English call set up
- Bilingual call option
- Set up the two language volunteer groups and tag language
- Call scheduling
- How to create AI-generated voice recordings for your phone system
- Examples of English and Spanish greetings and voicemail messages

The guide is written for trusted servants who have little or no experience with telephone configuration.
